# 历史文档归档

本目录保留 UAMS 开发过程中的审计、修复、部署与阶段报告，用于追溯决策与验收证据。

这些文档描述的是当时的状态，可能包含已过期的启动方式、端口、数据库版本或文件名；**日常操作请以 `docs/` 根目录的当前文档为准**。

| 类别 | 说明 |
|---|---|
| `UAMS_V3.1_*` | V3.1 功能审计、FIX-001～004、DEPLOY-001/002、PROD-001、启动管理器、登录错误修复 |
| `fixes/` | FIX-001～FIX-009 阶段任务说明与报告 |
| `V0.2_*` | V0.2 审计与复核 |
| `V2.0开发指南.md` / `V2.1_FINAL_BASELINE.md` | V2.x 阶段基线 |
| `DOCUMENTATION_UPDATE_REPORT.md` | 早期文档整理记录 |

> 归档文档中的链接若指向已移动文件，可能失效；不影响当前系统运行。
