# 历史文档归档

本目录保留 UAMS 开发过程中的审计、修复、部署与验收证据。
这些文档描述当时状态，可能包含已过期的启动方式、端口、数据库版本或文件名；
**日常操作请以 `docs/` 根目录的当前文档为准**。

```text
archive/
├── audits/    审计与差距分析
├── fixes/     阶段修复记录（FIX-001～009、V3.1 FIX/登录修复）
└── reports/   部署、验收、阶段基线与交付报告
```
