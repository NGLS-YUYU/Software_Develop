## V0.1 —— 基础原型 ✅

**已交付内容**

- 数据库：28 张表 / 47 外键 / 46 CHECK 约束，2 个 Alembic 迁移
- 后端：70 个 API 路径 / 108 个操作，56 个 Python 文件
- 前端：28 个页面（学生 7 / 教师 5 / 教务 12 / 公共 4）
- 核心业务闭环：课程 → 教学任务 → 教学班 → 排课 → 选课 → 课表 → 成绩 → 考试
- 关键机制：选课行级锁防超卖、排课冲突检测、先修课环路检测、成绩四态状态机、RBAC 权限隔离
- 演示数据：seed 脚本幂等，1 学院 / 2 专业 / 2 班级 / 5 教师 / 20 学生 / 10 课程
