# FIX-005：批量导入前端闭环

## 1. 来源

- 对应 TASK：TASK-010（基础数据 Excel 批量导入）
- 对应 RE-AUDIT 问题：问题 D（批量导入前端缺失，BACKEND_ONLY）

## 2. 当前状态

**已有代码（后端，真实可用）：**

| 端点 | 说明 | 权限 |
| --- | --- | --- |
| `GET /imports/templates/students` | 学生导入模板下载 | `student:write` |
| `GET /imports/templates/courses` | 课程导入模板下载 | `course:write` |
| `GET /imports/templates/grades` | 成绩导入模板下载 | `grade:write` |
| `POST /imports/students` | 学生批量导入（.xlsx） | `student:write` |
| `POST /imports/courses` | 课程批量导入（.xlsx） | `course:write` |
| `POST /imports/grades` | 成绩批量导入（.xlsx） | `grade:write` |

- Service：`app/services/import_service.py`（openpyxl 真实解析，错误行号返回，成绩复用 ScoreService）
- 实测：`GET /imports/templates/students` 返回 5004 字节真实 `.xlsx`（content-type 正确）

**已有前端：无。** `api/index.ts` 无 `importApi`；无导入按钮、无模板下载链接。

**缺失部分：** 学生/课程/成绩的模板下载、文件选择、上传、进度、结果展示全缺失。

**注意**：后端**只有学生/课程/成绩三类导入**，无「教师导入」。PRD 附录提到「学生/教师/课程/成绩导入导出」，但当前后端未实现教师导入。[NEEDS_CONFIRMATION] —— 本 FIX 只闭环已存在的 3 类导入；教师导入是否补做留待确认。

## 3. 修复目标

教务管理员在「学生管理」「课程管理」「成绩」对应页面（或统一导入页），可：下载模板 → 填写数据 → 选择 .xlsx → 上传 → 看到成功/失败数量与错误行信息 → 数据真实落库、页面刷新后可见。

## 4. 不在本 FIX 范围内

- **不重新实现假的 import API**，必须调用现有 `/imports/*`；
- 不改后端导入校验逻辑（已通过验收）；若接入时发现缺陷，单独报告；
- 不做「教师导入」「导出功能」——当前后端未实现，归后续任务，不在本 FIX。

## 5. 需要修改的文件

- `frontend/src/api/index.ts`（新增 `importApi`：`templatesStudents/templatesCourses/templatesGrades/importStudents/importCourses/importGrades`）
- `frontend/src/views/admin/Students.vue`、`Courses.vue`（导入 + 模板下载入口）；或新建统一导入组件 `frontend/src/components/ExcelImport.vue`
- `frontend/src/types/index.ts`（补导入结果类型 `{total,success,failed,errors[]}`，若缺）

## 6. 实现要求

- 模板下载：触发浏览器下载（`Content-Disposition` 已由后端返回 .xlsx）；
- 上传：`<el-upload>` 限制 `.xlsx`（后端 `_validate_ext` 最终校验），单文件；
- 结果展示：展示 `total / success / failed` 与 `errors[]`（行号 + 字段 + 错误信息）；
- 权限：菜单/按钮仅 ADMIN；后端权限码仍为最终校验；
- 导入成功后刷新对应列表。

## 7. 验收标准

```
下载学生模板（真实 .xlsx）→ 填写真实数据 → 上传 → POST /imports/students
→ MySQL students 表新增记录（users 账号联动创建）→ 页面显示 {total,success,failed,errors}
→ 非法行返回错误行号与字段 → 刷新学生列表可见新数据
→ teacher/student 访问 /imports/* 返回 403
```

- E2E/手工：按 §7 三类导入至少各走通一次，核对数据库。
